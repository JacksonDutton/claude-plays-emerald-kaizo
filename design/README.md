# Design documents

Working documents from the project, first copied on 20 October 2026 and updated on 28 and 29 October 2026 (`kaizo-milestone-times.md` and `transcript-analyses-2026-10-20.md` are still the 20 October copies). They were written for the study team (the supervisor and the companion Claude session), so they use its shorthand: arms B1, B2, Ripple (also K1.1) and K2; "the companion" is the Claude Opus session that monitors runs, logs interventions and keeps the record. Session identifiers are redacted. Times are UTC unless marked AEDT (UTC+11).

| File | What it is |
|---|---|
| `kaizo-baseline-protocol.md` | Pre-registration and running protocol for the first Kaizo pilot (B1), written 16 Oct before launch, with the launch log. |
| `scope-v2.md` | Scope as of 18 Oct: what is pilot and what is confirmatory, what freezes when, what is parked. |
| `kaizo-brief-v3-draft.md` | Freeze candidate of the agent brief for the six confirmatory arms, with the notes-arm and no-notes-arm lines marked. Not yet frozen. |
| `kaizo-v3-measures-draft.md` | Measures for the confirmatory arms: slip taxonomy, diary and joy-log coding, harness v3 change list. |
| `v3-decisions-2026-10-20.md` | The supervisor's answers to every open design question for v3, with the options as offered. |
| `kaizo-v3-fixed-texts.md` | Every message the companion may send a confirmatory arm (F1-F7), with exact text, trigger, grade and send rule. Signed off by the supervisor on 28 Oct, with the send rules amended the same day after review (texts unchanged); sha256 d9a9090f09ac821d…; any later change is a reported deviation. |
| `kaizo-K3-extraction-kit.md` | How the K3 notes pack is built from K2's own files: sources, distiller and auditor prompts, the mechanical filter (`tools/k3_filter.py`), provenance exclusion, sign-off and hash. To run after K2 ends. |
| `diary-framing-brendan-vs-k2.md` | Why Run 1's diary reads so differently from K2's, with numbers, the framing behind each, and the supervisor's 29 Oct decisions on what the six arms take from each. |
| `diary-protocol.md` | The diary-writing protocol and every dated instruction that changed how diary entries are written. |
| `diary-blind-coder-codebook.md` | Codebook and procedure for the blind second coder of diary feeling. |
| `kaizo-milestone-times.md` | Milestone definitions and times for every Kaizo arm, by progress-file audit and by transcript scoring. |
| `transcript-analyses-2026-10-20.md` | Results from the pilot transcripts: injected messages, habits and narration around compaction, milestone scoring, whiteouts, diary rewrites, the scrub, and account skills in the arm sessions. |
| `k3-launch-2026-11-07.md` | Public notes on K2's end, how the K3 notes pack was built (process and numbers only), the two voided K3 starts and K3's launch settings. |
| `k3-harness-fixes-2026-11-07.diff` | The harness patch made between the voided K3 starts (the text-advance command and the boot autopilot). |
| `k3-end-2026-11-10.md` | K3's end: what the 10 November audit found (no save on disk, tools offered beyond the brief, notes read once), the stop and exit interview, errors by the study team, and the plan and harness changes for K4. |
| `k4-k5-update-2026-11-13.md` | K4's result (one badge in 25 hours 28 minutes), the harness faults found while building K5, K5 and the side experiment K5F while running (splits to 13 November), the mid-run change to K5's diary instruction (K5b), and the first decisions and hypotheses for K6. |

`k4-k5-update-2026-11-13.md` gives interim figures for two runs that were still going when it was written. Some documents mention K2 interim results. K2 stopped on 7 November 2026; its full records come after review.
